# Đa ngôn ngữ

## Mục đích
Không hard-code chữ trên UI; hỗ trợ tiếng Việt (mặc định) và tiếng Anh, đổi ngôn ngữ ngay trong app.

## File / module liên quan
- `Resources/Strings.resx` (tiếng Anh, ngôn ngữ trung lập) và `Resources/Strings.vi.resx` (tiếng Việt).
- `Services/LocalizationService.cs` — `LocalizationService.Instance[key]`, `SetLanguage`, sự kiện
  `LanguageChanged`; lớp tắt `Loc.Get(key)` / `Loc.Format(key, args)`.
- `Views/TrExtension.cs` — markup extension `{v:Tr Key}` cho XAML.
- `Views/SettingsDialog.xaml(.cs)` — chọn ngôn ngữ; `MainWindow.xaml.cs` / `DocumentWorkspace` dựng lại chuỗi tạo bằng code khi `LanguageChanged`.
- `PDFEditorApp.Tests/I18nTests.cs`.

## Logic chính
- XAML: `Text="{v:Tr Menu_File}"` → binding tới indexer của `LocalizationService` → đổi ngôn ngữ thì
  `PropertyChanged("Item[]")` cập nhật mọi chữ ngay, không cần khởi động lại.
- C#: `Loc.Get("Key")`, `Loc.Format("Key", arg…)`. Chuỗi tạo bằng code (tiêu đề, trạng thái, panel) được
  dựng lại khi nhận sự kiện `LanguageChanged`.
- Thông báo lỗi: `Error_<PdfErrorKind>`.
- Ngôn ngữ lưu trong settings; chưa chọn → tiếng Việt (`LocalizationService.DefaultLanguage`).
- Đặt tên key: `Menu_*`, `Tip_*` (tooltip), `Panel_*`, `Info_*`, `Status_*`, `Msg_*`, `Dialog_*`, `Filter_*`,
  `Error_*`, `Export_*`, `Password_*`, `About_*`, `Empty_*`, `Common_*`, `Ribbon_*`, `Tool_*`, `Hint_Tool_*`, `Props_*`,
  `Home_*`, `Settings_*`, `Signature_*`, `Watermark_*`, `HeaderFooter_*`, `Position_*`, `Redact_*`, `Split_*`…
  Key ghép động trong code (`"Hint_Tool_" + tool`, `"Position_" + p`) được `UiResourceTests` kiểm tra riêng.
- Thêm chuỗi mới: thêm key vào CẢ HAI file resx (cùng placeholder `{0}`…). `Menu_*` dùng `_` cho phím tắt Alt.

## Lưu ý / giới hạn
- Hộp thoại dùng WPF-UI MessageBox với chữ nút lấy từ resx (`Dialogs` trong `Views/UiHelpers.cs`) nên theo ngôn ngữ app.
- Icon (`ui:SymbolIcon`), mã màu, tên font không phải chữ UI.
- `I18nTests` kiểm tra cả thuộc tính `Label`, `PlaceholderText`, `Message`, `OnContent`, `OffContent` của control WPF-UI / app.

## Cách test
- `I18nTests`: mọi key có ở cả hai file và không rỗng; placeholder khớp giữa hai ngôn ngữ; mọi key dùng trong
  XAML (`{v:Tr ...}`) và C# (`Loc.Get/Format("...")`) tồn tại; mỗi `PdfErrorKind` có `Error_*`; XAML không có
  chữ hard-code (thuộc tính Text/Content/Header/ToolTip/Title và nội dung TextBlock, Button…); đổi ngôn ngữ trả
  đúng chuỗi.
- Thủ công: Cài đặt → Ngôn ngữ → English / Tiếng Việt, kiểm tra ribbon, panel, thanh trạng thái đổi ngay.
